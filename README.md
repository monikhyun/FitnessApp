# 🏋️‍♀️ FitnessApp

**부위별 운동 기록, 식단 관리, 성장 시각화를 한 번에!**  
운동 루틴과 식습관을 지속적으로 관리할 수 있게 도와주는 피트니스 앱입니다.  
목표를 달성할 때마다 성장하는 나무를 통해 성취감을 느껴보세요. 🌳

---

## 📱 주요 기능

| 기능 | 설명 |
|------|------|
| 📅 **운동 캘린더** | 날짜별로 부위별 운동을 추가하고, 세트별 반복 횟수까지 기록할 수 있습니다. |
| 🍽️ **식단 관리** | 하루 섭취한 음식 기록 및 탄수화물, 단백질, 지방(탄단지)의 섭취량을 분석합니다. |
| 📊 **통계 시각화** | 월간/연간 기준으로 탄단지 섭취량을 그래프로 확인할 수 있습니다. |
| ➕ **음식 추가 기능** | 사용자가 오늘 먹은 음식을 직접 추가하여 관리할 수 있습니다. |
| 🌳 **목표 달성 시 성장하는 나무** | 목표를 달성하면 나무가 성장하여 성취감을 제공하는 시각적 피드백을 줍니다. |
